# Manish Singhal — Personal Portfolio Website

A modern, professional portfolio website built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

## 🌐 About This Project

This is the personal portfolio website of **Manish Singhal**, Senior Product Manager at HSBC, based in Milton Keynes & London, United Kingdom.

The site showcases:
- Professional intro & executive profile
- Full work experience timeline (HSBC, Barclaycard, Datix, NHS Trusts)
- Skills & expertise across Product Management, Digital Fraud, Risk & Cloud
- Featured programs & impact highlights
- Contact section with LinkedIn and GitHub links

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| Next.js 16 | React framework (App Router) |
| React 19 | UI rendering |
| Tailwind CSS v4 | Styling |
| TypeScript | Type-safe code |
| Lucide React | Icons |

## 🚀 Running Locally

1. Make sure you have **Node.js** installed.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open your browser at [http://localhost:3000](http://localhost:3000)

## 📦 Build for Production

```bash
npm run build
npm start
```
